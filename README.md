# GophKeeper

GophKeeper — это клиент-серверный менеджер паролей, позволяющий безопасно хранить, шифровать и синхронизировать приватные данные между несколькими устройствами пользователя.

Проект реализован на языке Go с использованием gRPC и PostgreSQL. Клиент представлен в виде CLI-приложения.

---

## Основные возможности

### Сервер
- Регистрация пользователей
- Аутентификация и авторизация (JWT)
- Безопасное хранение данных
- Синхронизация данных между клиентами
- gRPC API
- Поддержка TLS

### Клиент (CLI)
- Регистрация и вход
- Работа с локальным хранилищем
- Синхронизация с сервером
- Создание, обновление и удаление данных
- Просмотр данных
- Отображение версии приложения

---

## Поддерживаемые типы данных

- Логин/пароль
- Текстовые заметки
- Бинарные файлы
- Банковские карты

Для каждой записи поддерживается произвольная метаинформация (например: сайт, описание и т.д.)

---

## Архитектура
Используемые технологии:
- Go
- gRPC (Protocol Buffers)
- PostgreSQL
- JWT
- bcrypt
- TLS
- Клиентское шифрование данных

---

## Безопасность

- Пароли хранятся в виде хэшей (bcrypt)
- Данные шифруются на стороне клиента
- Сервер не имеет доступа к исходным данным
- Используется JWT для авторизации
- Поддерживается TLS
